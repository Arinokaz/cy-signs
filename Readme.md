🇨🇾 Cyprus Driving Test Quiz — Техническая документация
1. Обзор проекта
Интерактивное веб-приложение для подготовки к экзамену на знание дорожных знаков Кипра. Проект ориентирован на запоминание через практику с использованием системы умных подсказок.

2. Архитектура данных
Данные разделены на логические блоки для удобства масштабирования. Каждый знак представлен в виде объекта:

JavaScript
{
    name: "Название (RU/EN)",
    file: "имя_файла.svg",
    cat: "warning | regulatory | mandatory | information | police | markings",
    hint: "Ассоциация или правило для запоминания"
}
Всего знаков: 217.

Категории:

warning: Предупреждающие (красные треугольники).

regulatory: Запрещающие и приоритетные (красные круги/ромбы).

mandatory: Предписывающие (синие круги).

information: Информационные и указатели (синие/белые квадраты).

police: Жесты регулировщика.

markings: Дорожная разметка (желтые линии, зигзаги).

3. Сценарий работы (User Flow)
Настройка: Пользователь выбирает категорию знаков (или «Все») и количество вопросов.

Генерация: Система перемешивает массив данных, отбирает нужное кол-во объектов и генерирует 4 варианта ответа (1 правильный + 3 случайных дистрактора той же категории для сложности).

Процесс:

При правильном ответе — переход к следующему вопросу.

При ошибке — кнопка подсвечивается красным, и появляется блок .hint-box с пояснением (поле hint), помогая понять логику знака.

Финал: Вывод общего счета и подробный лог ошибок с изображениями знаков, на которых пользователь ошибся.

4. Технологический стек
HTML5/CSS3: Адаптивная верстка, анимации fadeIn для интерфейса, Flexbox для сеток.

Pure JavaScript (ES6+): * Динамическое управление DOM.

Использование Spread-операторов (...) для объединения массивов.

Алгоритмы перемешивания (Shuffle).

5. Возможности для масштабирования (Backlog)
Если понадобится улучшить проект, вот готовые направления:

Система весов: Чаще показывать те знаки, в которых пользователь ошибался (на основе localStorage).

Таймер: Режим «Экзамен» с ограничением времени на ответ.

Мультиязычность: Вынос строк в отдельный конфиг для переключения между RU/EN/EL.

Звуковые эффекты: Озвучка жестов регулировщика для лучшего запоминания.

6. Как поддерживать базу
Новые знаки добавляются в массив ALL_SIGNS. При добавлении изображения важно соблюдать camelCase или snake_case в названиях файлов и проверять их наличие в папке /assets/ (или соответствующем пути).
